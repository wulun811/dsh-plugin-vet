# 失败清单（FAILURES）

这个文件记的是**已经发生过的错**，不是待办、不是威胁模型。每条都来自真实提交与真实观测，格式固定：
现象 → 根因 → 现在由什么挡住 → 教训。加一条的门槛是：**它有具体的错误产物**（一条谎话、一个假绿、
一个静默失效），不是"可以考虑改进"。

维护纪律：修了一个 bug 却没让某条不变式或某个测试变强，就在"现在由什么挡住"里写"只靠 code review"。
那是最诚实的一档，也是最该尽快换掉的一档。
